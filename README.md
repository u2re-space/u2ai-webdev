# u2ai-webdev

`ai-webdev` — консольный ИИ-инструмент для веб-разработки: планирование проекта,
разметка, код, стили, компоненты, иконки, окружение и ревью.

Пакет `@u2ai/webdev`, Node.js >= 26, ESM, без SDK (чистый `fetch`).
Конфиг: `~/.ai-webdev` (оверрайд `AI_WEBDEV_HOME`).

```bash
npm install -g @u2ai/webdev
ai-webdev --help
```

Статус: alpha. Пакет в работе — состав команд и стадий описан в `planned.md`
репозитория <https://github.com/u2re-space/u2ai-webdev>.
